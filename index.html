📅 지난주 회고 — TOP 3

1. Google I/O 2026 — Gemini Omni·Spark 공개

구글이 차세대 모델 Gemini Omni(텍스트·이미지·오디오·비디오 모두 처리 + 영상 출력)와 Spark(멀티앱 에이전트)를 공개. AI 모델의 멀티모달화가 본격화됐고, "아젠틱 시대" 신호탄.

왜 중요했나: yeyak의 guest journey 전체를 AI가 자동화할 수 있다는 신호. 경쟁사(Airbnb) 신기능 러시와 맞물려 urgency 높음.

2. Airbnb Summer Release — 호스트부터 게스트까지 전 여정 AI화

Airbnb가 Smart Setup(호스트 등록 자동화), AI 비교 도구, AI 챗봇(CS 40% 자동화) 등을 일괄 공개. 호스트의 마찰 제거가 핵심 전략.

왜 중요했나: Partner(호스트) 온보딩과 CS 효율화 패턴을 직접 제시. yeyak의 partner app 설계에 즉시 참고 가능.

3. Google Agentic Booking 정식 출시 — OTA 모델 위협

구글이 호텔 Agentic Booking을 정식 출시. 사용자가 구글에서 "부산 출장" 한 마디 하면 AI가 검색·비교·예약까지 직접 처리. OTA 방문을 우회.

왜 중요했나: Direct Booking 준비 + AEO(Answer Engine Optimization) 전략이 필수. yeyak의 API 노출 방식 재검토 필요.

Airbnb Summer Release (5/20) — 게스트 여정 전체에 AI 박았다

Airbnb가 이번 주(수요일) 발표한 대형 업데이트. 호스트의 숙소 등록부터 게스트의 검색·비교·예약·CS까지 모든 단계에 AI 도입. 특히:

  • Smart Setup: 호스트가 사진만 올리면 AI가 방·어메니티·위치 설명 자동 작성
  • AI 비교 도구: 두 숙소를 옆에 놓고 AI가 차이점(레이아웃·디자인·입지) 강조
  • AI 챗봇: CS 문의의 40%를 자동 처리, 11개 언어 지원
yeyak에 시사하는 점: 파트너 어드민(호스트=숙소 운영자)의 등록 마찰을 AI가 없앤다는 게 핵심. yeyak의 partner 앱에 적용 가능한 패턴이고, buyer 쪽 검색·비교 UX에도 영감 큼. i18n 챗봇 40% 자동화 수치는 CS 비용 절감 ROI 산정에 인용할 수 있음.

Google, 호텔 Agentic Booking 정식 출시 — AI가 검색·비교·예약을 다 한다

구글이 이번 달 정식 공개한 기능. 사용자가 "다음 달 부산 출장, 5만원대 조식포함" 한 마디 하면 AI가 알아서 인벤토리 검색 → 가격 비교 → 예약까지 직접 처리. Google Maps·검색·개인 이력과 연동.

yeyak에 시사하는 점: 이중 영향. ① 위협 — 사용자가 OTA 사이트를 방문 안 하고 구글에서 끝낼 가능성. SEO를 넘어 AI 검색 노출(AEO·Answer Engine Optimization)이 새 격전지. ② 기회 — Direct Booking 시스템이 AI 에이전트와 잘 연동되도록 API 노출 방식 재검토 필요. yeyak의 partner API 스펙을 "AI 에이전트가 잘 부르도록" 다듬는 게 다음 분기 어젠다일 수 있음.
